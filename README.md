# День из жизни банка

Браузерная игра в жанре **point-and-click** с видом от первого лица про профессии в банке (кейс банка «Центр-инвест», Cyber Garden School 2026).
Игрок выбирает одну из профессий — **Пентестер («белый хакер»)** или **Клиентский менеджер**, осматривает комнаты банка, кликает по предметам и персонажам и видит, как решения в одной роли меняют смену в другой.

> **Текущий этап:** выполнены **Шаги 1–3** — меню старта, экран комнаты с зонами и картой точек, система **Interactable** (меню действий над объектами), инвентарь из `content/items.json` и флаги мира `worldState` (`getFlag` / `setFlag`).

## Как всё устроено: схема «что с чем связано»

Представь обычный театр или квест-книгу с иллюстрациями:
- **Папка `/public/rooms`** — это **декорации (задники и накладные слои комнат)**. Сейчас там лежат цветные SVG-заглушки. Когда дизайнер нарисует готовые фоны, их можно просто положить вместо старых файлов с теми же именами — код менять не придётся.
- **Папка `/content`** — это **сценарий, предметы и карта здания**. В `world.json` записаны все 7 точек-комнат, переходы между ними, интерактивные объекты (`hotspots`) с действиями (`inspect`, `pickup`, `use`, `talk`) и условиями по флагам мира. В `items.json` лежит справочник предметов инвентаря.
- **Папка `/src/engine`** — это **движок правил**. Он проверяет JSON-файлы на ошибки (`contentLoader.ts`), управляет флагами мира через `getFlag` / `setFlag` (`worldFlags.ts`), решает, какие зоны и слои видны и какие действия доступны (`worldEngine.ts`), и сохраняет прогресс в `localStorage` (`storage.ts`).
- **Папка `/src/ui`** — это **экран и кнопки**, которые видит игрок (главное меню, экран комнаты с меню действий, окно инвентаря по клавише `Tab`, карта точек).
- **Файл `src/theme.ts`** — это **палитра художника**: цвета заглушек комнат, подсветки зон, кнопок и шрифты лежат в одном месте.

```text
  [ /public/rooms/*.svg ] ──(картинки комнат и слои)──┐
                                                      ▼
  [ /content/*.json ] ──▶ [ /src/engine/contentLoader.ts ] ──▶ [ /src/App.tsx ] ◀──▶ [ storage.ts (localStorage) ]
                                                                     │
  [ /src/theme.ts ] ──(цвета и шрифты)───────────────────────────────┼──▶ [ RoomScreen.tsx / PointMap.tsx / MainMenu.tsx ]
                                                                     ▲
                                       [ /src/engine/worldEngine.ts ]┘
```

## Словарь терминов простыми словами

- **Point-and-click** — жанр игры «наведи и нажми»: игрок осматривает комнату своими глазами, наводит мышь на предметы или людей, читает подсказки и переходит в соседние комнаты по клику.
- **Hotspot (кликабельная зона)** — невидимый (или подсвеченный) прямоугольник поверх картинки комнаты, заданный в процентах от её ширины и высоты. Благодаря процентам клики попадают точно в предмет на любом размере монитора.
- **Параллакс** — лёгкое смещение фона вслед за движением мышки, создающее живой эффект присутствия «от первого лица», при этом кнопки интерфейса остаются на месте.
- **Node.js и npm** — инструменты разработчика. `npm` скачивает нужные библиотеки из `package.json`.
- **Vite** — локальный сервер и сборщик, который запускает сайт на `http://localhost:3000`.
- **React + TypeScript** — основа интерфейса и проверка кода на ошибки до запуска.
- **`localStorage`** — встроенный «блокнот» браузера на компьютере игрока. Хранит никнейм, сложность, текущую комнату и флаги мира локально, без отправки на сервер.
- **Флаги мира (`worldState`)** — переключатели последствий. Например, если `stickyPasswordLeft: true`, в комнате «Окно обслуживания» появится слой со стикером на мониторе.

## Как запустить игру

1. Откройте папку проекта в терминале.
2. Установите зависимости (делается один раз):
   ```bash
   npm install
   ```
3. Запустите игру:
   ```bash
   npm run dev
   ```
4. Откройте браузер и перейдите по адресу: `http://localhost:3000`.

Для сборки готовой статической версии:
```bash
npm run build
```

## Как менять контент и картинки без программирования

### Как заменить фоны комнат
Положите готовые файлы (`.jpg`, `.svg` или `.png`) в папку `public/rooms/` под теми же именами (`entrance.jpg`, `hall.jpg`, `counter.svg`, `office.jpg`, `meeting.jpg`, `corridor.jpg`, `server_room.jpg`) или укажите новое имя файла в поле `"background"` внутри `content/world.json`.

### Как добавить комнату, переход или предмет в комнату
Откройте `content/world.json`:
- В списке `points` находятся комнаты (точки). У каждой есть `id`, название `title`, фон `background`, координаты на карте `mapCoords` (в процентах `0–100`), выходы `exits` и кликабельные зоны `hotspots`.
- Чтобы подвинуть зону, измените её проценты `x`, `y`, `width`, `height`.

### Как поменять любой текст интерфейса
Откройте `content/ui.json` и отредактируйте нужную строку в кавычках.

### Как изменить или добавить уровень сложности
Откройте `content/difficulty.json` и отредактируйте список `profiles`.

### Как добавить новую профессию (роль)
Создайте новый файл в `content/roles/`, например `content/roles/security.json`, по образцу `pentester.json`, указав `startPoint` из `content/world.json`. Код движка менять не нужно.

### Как поменять цвета комнат-заглушек и подсветки
Откройте `src/theme.ts` и измените цвета в разделах `roomColors`, `hotspotColors` или `colors`.
